## Activate the extension
- To activate the extension, the icon should be clicked.
- To deactivate the extension, the icon should be clicked again.

## Button "Add Text Area"
- Click to add a text area where you can write notes. Clicking again the button disappears the text area. The text inside the text area persists after clicking the button.
- The size of the text area can be changed by dragging the botton right corner.

## Button "Copy Text"
- Copy the text inside the text area. This button only appears if the text area is active.

## Key combinations
- ctrl + z: undo
- ctrl + shift + z: redo

# Important
The information is lost after refreshing the page.
